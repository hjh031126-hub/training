# 2026 부산대학교 직무연수 종합 안내 웹사이트

미래 교육과 스마트 대학 행정을 선도하는 **2026 부산대학교 교직원 직무연수 종합 안내 포털**입니다.  
구글 스프레드시트의 연수 데이터를 실시간으로 동기화하여 연수생들에게 최신의 커리큘럼과 수강 정보를 제공합니다.

---

## 🌟 주요 기능

1. **구글 시트 실시간 동기화 (Google Sheets Live Sync)**
   - 구글 시트(`2026_부산대_직무연수_카탈로그_실습.xlsx`)의 데이터를 실시간으로 패치
   - PapaParse 기반 파싱으로 콤마, 개행 문자를 안전하게 처리
   - 타임스탬프 캐시 무효화(`_t=${Date.now()}`) 및 `no-cache` 정책 적용으로 시트 수정 시 새로고침만으로 즉시 반영

2. **메인 페이지 (`index.html`)**
   - **대시보드 통계 카드**: 전체 과정(32개), 필수 법정교육, 집합/실습, AI/정보화 과정 수 자동 집계
   - **복합 필터링 제어판**:
     - 10개 직무 분야(법정의무교육, 정보화·AI·데이터, 대학행정 특화 등) 원클릭 칩 필터
     - 대상(전직원, 실무자, 신규자, 관리자)별 드롭다운 필터
     - 이수구분(필수, 권장, 선택) 및 교육방식(온라인, 집합, 혼합) 필터
   - **실시간 디바운스 검색**: 과정명, 과정코드, 담당부서, 키워드 검색
   - **반응형 카드 그리드**: 모바일, 태블릿, 데스크톱 최적화 레이아웃 및 부드러운 호버 모션

3. **상세 페이지 (`detail.html`)**
   - URL 쿼리 파라미터(`?id=PNU-2026-xxx`)를 기반으로 개별 연수 정보 실시간 매칭
   - 세부 교육 안내, 체크리스트 형식의 학습 목표, 넘버링 뱃지 형태의 커리큘럼 모듈
   - 우측 플로팅 요약 카드 및 [수강신청 바로가기] 외부 링크 연동
   - 동일 분야 연관 연수 3건 추천 영역

```

├── css/
│   └── style.css       # 부산대 PNU Blue 테마 및 반응형 스타일
├── js/
│   ├── sheet-api.js    # 구글 시트 실시간 연동 및 PapaParse 파싱
│   ├── main.js         # 메인 페이지 필터/검색 및 카드 렌더링
│   └── detail.js       # 상세 페이지 파라미터 매칭 및 세부 커리큘럼 렌더링
├── WORK_PLAN.md        # 작업 기획서
└── README.md           # 프로젝트 안내서
```
